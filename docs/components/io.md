# xqsr3 IO <!-- omit in toc -->

The IO components provide small output helpers for Ruby streams.


## Table of Contents <!-- omit in toc -->

- [Loading](#loading)
- [Components](#components)


## Loading

```Ruby
require 'xqsr3/io'
```


## Components

### `IO#writelines`

Writes a sequence of lines to an IO object.

```Ruby
require 'xqsr3/io/writelines'
```

The same functionality is exposed through the `IO#writelines` extension.
